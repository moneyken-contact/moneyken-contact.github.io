# ЖК «Олимпиец» — версия для GitHub Pages

Архив содержит полностью статический сайт без сборки и серверных зависимостей.

## Как разместить

1. Скопируйте содержимое этой папки в корень репозитория GitHub Pages.
2. В настройках репозитория откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

Если сайт размещается не в корне репозитория, относительные пути продолжат работать.
